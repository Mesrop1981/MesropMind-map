> Китайское название: 思绪思维导图 (Thoughts Mind Map). Простая и мощная библиотека веб-интерфейса и приложение для создания интеллект-карт (диаграмм связей).
> 
> Проект состоит из двух частей: библиотеки с открытым исходным кодом на JavaScript и десктопного приложения.

# Библиотека и Web-версия
> Код в данном репозитории. В настоящее время находится в режиме поддержки.

- **JS-библиотека для создания интеллект-карт**, не зависящая от конкретных фреймворков. Ее можно использовать для быстрой разработки собственных веб-продуктов для работы с ментальными картами.
  > Документация разработчика: [https://wanglin2.github.io/mind-map-docs/](https://wanglin2.github.io/mind-map-docs/)
- **Веб-версия**, созданная на основе библиотеки с использованием `Vue 2.x` и `ElementUI`. Поддерживает работу с локальными файлами на компьютере, может использоваться как онлайн-приложение, а также подходит для самостоятельного развертывания и доработки.
  > Онлайн-версия: [https://web.sxmind.cn/](https://web.sxmind.cn/)

Подробнее: [Дополнительная документация](./README_MORE_ZH.md).

# Десктопное приложение и плагины
> Исходный код десктопного приложения и плагинов закрыт, они активно разрабатываются и поддерживаются.
> 
> Официальный сайт продукта: [https://sxmind.cn/](https://sxmind.cn/)

## Клиент «Thoughts Mind Map» (思绪思维导图)
Локальное хранение, приоритет приватности, безопасность данных, приложение работает полностью без подключения к интернету!

- [x] 1. Поддержка создания неограниченного числа файлов, узлов (включая свободные узлы) и шаблонов;
- [x] 2. Богатые настройки: базовые параметры, кастомизация шрифтов, горячих клавиш, контекстного меню, иконки, конфигурация хранилищ изображений, настройки ИИ, облачной синхронизации WebDAV и многое другое;
- [x] 3. Поддержка множества структур: классическая ментальная карта, логическая структура, структура дерева, организационная диаграмма, временная шкала (таймлайн), рыболовная кость (диаграмма Исикавы), таблицы и др.;
- [x] 4. Встроено более сотни красивых тем оформления, а также поддержка пользовательских тем и генерации тем с помощью ИИ;
- [x] 5. Возможность добавлять в узлы текст, изображения, ссылки, иконки, примечания, вложения, теги, резюме, связи, внешние рамки, маркеры, задачи, описания, нумерацию, математические формулы и т.д.;
- [x] 6. Импорт файлов форматов XMind, FreeMind, Markdown, TXT, XLSX; экспорт в PNG, XMind, SVG, PDF, Markdown, TXT, XLSX, FreeMind, Mermaid, HTML и другие форматы;
- [x] 7. Гибкая настройка стилей: текста, границ, фона, фигур, линий, внутренних и внешних отступов, макета изображений и тегов;
- [x] 8. Полезные и интересные функции: управление версиями, режим презентации, генерация через ИИ, стиль от руки, редактирование структуры (оглавления), водяные знаки, полосы прокрутки, выравнивание одноуровневых узлов, мини-карта, переход к выбранному узлу, разноцветные линии (радужные линии), двусторонние ссылки между узлами, поиск и замена и т.д.

Поддерживает ОС Windows, Mac и Linux. Доступные языки: упрощенный китайский, традиционный китайский, английский, вьетнамский, **русский**, японский, корейский, немецкий, французский, португальский.
